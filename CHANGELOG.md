# Changelog

All notable changes to the RaceDay API project will be documented in this file.

## [1.0.0] - 2026-10-20

### Added
- Initial project setup with ASP.NET Core Web API
- Entity Framework Core with Code-First approach
- User authentication with BCrypt password hashing
- Session-based authentication middleware
- Role-based access control (Organiser/Participant)
- Event management endpoints
- Category management endpoints
- Event enrolment system
- Results capture and tracking
- Swagger/OpenAPI integration
- Comprehensive unit test suite
- GitHub Actions CI/CD pipeline
- Complete documentation

### Security
- Password hashing using BCrypt
- Session-based authentication
- Role-based authorization
- Protected endpoints

### Testing
- 25 unit tests covering all major functionality
- Tests for authentication
- Tests for event management
- Tests for role-based access control
- Tests for enrolments
